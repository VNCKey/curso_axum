# curso_axum

Curso práctico de Tokio, Axum, SQLx y SQLite con Rust.

El proyecto evoluciona desde un servidor HTTP básico hasta una API CRUD organizada con la arquitectura DFE:

- `api/`: entrada HTTP y respuestas
- `flows/`: casos de uso
- `domain/`: reglas del dominio
- `fx/`: efectos externos, como la base de datos

## Ejecutar

```bash
cargo run
```
